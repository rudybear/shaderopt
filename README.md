# shaderopt

A measurement-driven lab that automatically finds the most performant version of post-processing shaders on desktop, Android and iOS, within a user-controlled quality budget. See `AXIOM_SHADER_LAB.md` for the full brief.

Dependencies (not vendored):
- `~/sources/axiom-compute`: AXIOM-Compute, read-only; changes go through the `axiom-guru` guardian skill.
- `~/sources/igl`: Meta IGL, pinned to `6804e57c74bba676168a30bba20f976567240e1a`.
