# M1 report: sandbox MVP and faithful lift (desktop)

Date: 2026-09-24. Device: NVIDIA RTX PRO 6000 Blackwell, driver 580.178.04, Vulkan 1.4.312, P0 at 2625 MHz, clocks unlocked (locking needs sudo), no throttling. Tools: `lab/TOOLS.md`. Reproduce: `VERIFY.md`.

## 1. Baseline plays

All 19 scenarios (9 shaders, 13 train / 6 holdout) run through the IGL runner headless with the Khronos validation layer on and **0 validation errors**. Baseline medians at 1080p, K=8 executions per sample, 10 samples (`lab/results.jsonl`):

| Pass | Median GPU time |
|---|---|
| bloom threshold (half res, RGBA16F) | 6.5 us |
| blur_h / blur_v (half res) | 5.0 / 4.9 us |
| bloom composite (sRGB8) | 7.5 us |
| tonemap_aces | 8.0 us (16.6 us at 3440x1440) |
| color_grade | 6.9 us |
| fxaa, edges input | 23.8 us |
| fxaa, noise input | **56.2 us** |
| vignette_grain | 6.7 us |
| deferred_lit | 22.9 us |

Observation for M2: FXAA's cost more than doubles when the early-out branch stops taking; the branch is the whole cost story for that shader.

**A/A noise floor** (vignette_gradient, 3 rounds x 2 x 30 samples): relative difference of medians **-0.09%**, bootstrap 95% CI [-0.30%, +0.00%], coefficient of variation 0.60%. The timing gate's floor for this device and session is therefore the brief's 2% minimum, not the noise.

Per-pass time is stable across K=4..32 (tonemap 8.0 -> 7.7 us); K=1 reads 9.3 us because per-render-pass setup is then included. Timestamps use IGL's `ITimestampQueries` with BOTTOM_OF_PIPE at both ends, so consecutive passes do not overlap.

## 3. Faithful lift

- **Round trip.** The empty edit set reproduces every corpus SPIR-V module body byte for byte through rspirv 0.12 `dr::Module`. The single difference is header word 2, the generator magic (glslang `0x8000b` -> rspirv `0xf0000`). `shader-ir roundtrip` checks this and is part of `lab verify`.
- **CPU f32 model vs GPU.** `lab lift-check --split train`: **16 of 16 pass checks OK**. Error is measured in code units of the storage format (8-bit codes after sRGB encoding where applicable; f16 ULPs for HDR intermediates), feeding each pass the GPU's own readback of its inputs. Tolerance (`lab/lift_tolerances.toml`): p99 <= 1 code, max <= 4 codes. Measured: every non-fragile pass has p99 <= 1 and **max <= 1 code**; smooth inputs are bit-exact through the whole bloom chain.
- **Two model corrections were needed to get there, both documented:**
  1. Texture sampling: the GPU converts unnormalized coordinates to 8-bit fixed point by rounding to nearest before taking bilinear weights. Full-precision weights left up to 5 codes of error next to 64x-bright edges; truncation was worse (101 codes); round-to-nearest reproduces the GPU bit for bit.
  2. The remaining 1-code differences come from the NVIDIA compiler contracting `a*b+c` into FMA; the CPU model computes IEEE f32 per instruction. This is a prediction-vs-device gap by design (brief §8).
- **Precision-fragile shader flagged:** `vignette_grain`. Its hash chains `fract()` of large products, so a 1-ULP difference flips the whole grain value; 35% of pixels differ by more than one code (max 11 codes = the grain amount). Tolerated only under its `fragile` entry, and a candidate for the M2 sensitivity report.

## 4. Deviations from the brief and open items

- IGL's `--headless` shell mode cannot be used on this driver (driver bug); the runner creates the device with no surface instead.
- IGL does not enable `VK_KHR_shader_float_controls2` (`lab/IGL_PATCHES.md` #1); needed before M4 fast-math experiments.
- Descriptor sets: IGL hardwires set 1 for buffers; the runner patches the decoration (`lab/CONTRACTS.md`).
- Clocks are not locked (sudo). The noise floor is already far below the 2% gate.
- No mobile devices yet. Everything above is desktop only.
